# Живая демонстрация Freedom CQA

Показывайте приложение, а не слайды: http://127.0.0.1:8000/.

## Перед показом

1. Запустите `python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --workers 1` из папки проекта.
2. Откройте сайт в роли «Руководитель». Проверьте наличие диалогов и актуальных оценок.
3. Для оценки нового диалога нужен настроенный `OPENAI_API_KEY` и доступ к OpenAI. Локального лимита количества оценок нет. Новые запросы выполняются только по явной кнопке оценки или выбранному пользователем пакету; счётчики сохраняются для учёта расхода.
4. Заранее выберите один диалог с актуальной оценкой и, если такой есть, один с грубой ошибкой. При отсутствии актуальных классификаций интерфейс честно покажет пустой результат.

## Что показать

| Запрос во время презентации | Действия в интерфейсе | Что проверить |
|---|---|---|
| Все диалоги с грубыми ошибками | В «Диалогах» включите «Грубые ошибки». Другой путь: «Аналитика» → «Показать диалоги с грубыми ошибками». | В списке только диалоги с актуальным положительным флагом. В карточке есть отдельный блок с причиной и ссылкой «К фрагменту». Старые оценки в фильтр не входят. |
| Почему выставлены баллы | Выберите оценённый диалог, просмотрите причины снижения и все критерии, нажмите ссылку на реплику. | Переписка прокручивается и выделяет источник. Для звонка с записью также доступен переход к аудио. Итог, вклад критериев, объяснения и решения по апелляциям доступны рядом. |
| Как подать апелляцию | Переключитесь на «Оператор», у нужного критерия нажмите «Оспорить оценку», заполните основание и отправьте. | Статус ожидает решения. В роли «Руководитель» откройте «Апелляции», нажмите «Рассмотреть», выберите решение и сохраните причину. История и исходное обоснование сохраняются. |
| Как изменить чек-лист | В роли «Руководитель» откройте «Правила оценки», измените вес и сохраните. Затем отредактируйте правило или добавьте критерий. | Только вес: локальный пересчёт без ИИ. Новое правило/критерий: предыдущие оценки помечаются устаревшими, нужен отдельный анализ. Не выдавайте старый результат за оценку по новым правилам. |
| Анализ нового диалога | «Загрузить диалог» → TXT/DOCX/PDF/JSON или вставка текста → проверить участников/язык → «Добавить диалог» → «Оценить диалог». | Загрузка не вызывает модель. Оценка — отдельный платный запрос по вашему нажатию. Доказательства должны вести к репликам именно загруженного диалога. |

После показа апелляций и изменений правил при необходимости верните исходные настройки. Для репетиции используйте отдельную копию файла хранилища через `DATA_STORE_PATH`; не подменяйте результаты модели выдуманными оценками.

## Что проверено без оплаты модели

Автоматический интеграционный тест проходит импорт → оценку тестовой реализацией evaluator → фильтр флага → апелляцию → решение → локальный пересчёт веса → новый критерий → повторную оценку тестовой реализацией. Это проверка процесса, не смысловой точности модели.

Браузерная репетиция выполнена на отдельной копии хранилища с настоящими сохранёнными ответами OpenAI. Для показа положительного флага в копии восстановлен архивный ответ `p1-ru-029`; доказательства предварительно сверены с исходной перепиской. Основные данные, оценки и бюджет не менялись. Новые платные запросы при этой репетиции не выполнялись.
