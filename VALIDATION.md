## Проверка и исправления ошибок

Предыдущий прогон: `python -m pytest -q` — 47 проверок; `node --test tests/frontend.test.cjs` — 14 проверок. Всего `47 + 14 = 61`, все прошли. `node --check frontend/app.js` и компиляция Python завершились успешно. Внешние вызовы модели заменены тестовыми реализациями.

Исправлены и проверены:

- Фильтры выбирают диалог из текущего списка. Пустой результат очищает переписку, оценку и плеер; предыдущая запись останавливается.
- Запоздалые ответы выбора диалога и поиска не заменяют более новый результат. Обновление списка повторяет действующий поиск по полной переписке.
- Перемотка по MM:SS учитывает начало разговора, а отложенный переход отменяется при смене диалога или выборе другой цитаты. Изменение ссылки на запись обновляет URL кэша.
- Форма апелляции сохраняет номер диалога и оценки при открытии. Ручное решение показывается основным обоснованием, исходное доступно отдельно. Переключение N/A в редакторе сохраняет текст условия.
- При ошибке записи хранилище откатывается к последнему сохранённому состоянию. Неудачная запись резерва не вызывает модель; неудачное сохранение результата не показывает несохранённую оценку. Полученный usage сохраняется отдельно, когда повторная локальная запись возможна.
- Апелляции к исключённым из группы диалогам переходят в предыдущую версию. Их оценки не включаются в массовый пересчёт текущей группы.
- Пустые правила, логические значения вместо числовых оценок, некорректные записи датасета и неверная структура ответа модели отклоняются. Импорт файла больше не запускает приложение и не создаёт его хранилище.
- HTML аудиоплеера собирается из всех HTTP-фрагментов в пределах лимита; запросы Range разрешены для настроенных CORS-источников.
- Общая инструкция модели больше не переопределяет изменённые правила по фиксированным номерам критериев. Платная проверка нового промпта не выполнялась, точность смысловой оценки не подтверждена этим прогоном.

В браузере на сохранённых данных проверены фильтр «Проверено» с автоматическим выбором KZ, пустой результат EN + звонки с остановкой плеера, поиск по номеру с обновлением и сохранность условия N/A при переключении. Кэшированные оценки и число платных попыток сохранены. На этом этапе счётчик OpenAI составлял 3 попытки; новых запросов при этих исправлениях не было.

### Ошибка запуска тестов и защита от повторения

При первой проверке этой переработки pytest обнаружил временный скрипт по стандартному шаблону `*_test.py` и выполнил его код верхнего уровня. Произошёл один незапланированный платный запрос для RU: `3008 + 522 = 3530` токенов. Эта ошибка была сообщена пользователю. Результат перенесён в историю, две прежние текущие оценки восстановлены, расход и событие сохранены. Рабочий счётчик теперь 4 при лимите 3; оставшихся проверок 0. Расход отдельного трёхзапросного тестового хранилища в этот счётчик не входит.

Добавлены `pytest.ini` с каталогом `tests`, шаблоном `test_*.py` и исключением временных каталогов, autouse-фикстура с подменой ключа и запретом платного `Completions.create`. Временный скрипт получил main-guard и явно изолированное хранилище. Повторные 69 тестов прошли с этой защитой. Подробности и резервная копия сохранены локально в `output/incident-20261107`; платный расход не скрыт и не обнулён.
